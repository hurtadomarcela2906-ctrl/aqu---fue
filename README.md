# Aquí Fue en el celular

Aquí están el **costeo** y el **análisis** de Aquí Fue como aplicaciones que se instalan en el celular.
Los datos siguen en tus hojas de Google; estos archivos solo son la "pantalla".

Todo está en la misma carpeta (no hay subcarpetas): `index.html` es el inicio, `costeo.html` y `analisis.html` son las dos aplicaciones, y `conectar.html` es donde pegas, una sola vez en cada celular, el enlace de tu Apps Script (el que termina en /exec).
